# Карта сотрудников: отдельное окно, назначение задач, треки в демо

## 1. Открытие карты в новом окне
- Новый маршрут `/employee-map` (доступ: hrd, hr, company_admin, manager, superadmin) с полноэкранной страницей карты.
- На дашборде HRD во вкладке «Карта» — кнопка «Открыть в новом окне» (`target="_blank"` на `/employee-map`).
- На полноэкранной странице карта занимает всю высоту окна вместо 70vh.

## 2. Убрать мини-карту
- Удалить компонент `MiniMap` из графа React Flow. Навигация остаётся: хлебные крошки, зум, кнопки Controls.

## 3. Задача автоматически на выбранного сотрудника
- Кнопка «Новая задача» уже передаёт выбранного сотрудника, но список исполнителей сбрасывается некорректно при повторных открытиях: гарантируем, что при открытой карточке сотрудника он всегда предвыбран и подсвечен в диалоге.
- В карточке сотрудника (правая панель) добавляем кнопку «Назначить задачу» — открывает диалог сразу с этим сотрудником.
- Если карточка не открыта, диалог открывается без предвыбора (как сейчас).

## 4. Назначение задачи на отдел / группу (динамическая аудитория)
Задача привязывается к правилу аудитории; новые сотрудники, попадающие под правило, получают её автоматически.

- В диалоге создания задачи — переключатель режима:
  - «Конкретные сотрудники» (как сейчас);
  - «Аудитория»: отделы, должности, грейды (множественный выбор), с предпросмотром «Попадает N сотрудников».
- Сохранённое правило показывается в списке задач как бейдж («Отдел: Продажи»).
- Пересчёт аудитории: при выдаче задач сотруднику и при изменении отдела/должности/грейда профиля исполнители досоздаются.

## 5. Карьерные треки в демо-компании «ООО Демо»
Сейчас сидер создаёт шаблоны треков, сценарии шагов и связи должностей, но ни один сотрудник на трек не назначен, поэтому раздел выглядит пустым.
- Добавить в сидер назначение треков: ~40% сотрудников получают активный трек, соответствующий их текущей должности.
- Разложить прогресс: часть на шаге 1, часть в середине, часть завершила трек; сгенерировать личные цели (career_goals) по шагам и несколько отправленных/одобренных шагов.
- Сброс демо-компании уже чистит эти таблицы — доп. изменений не требуется.

## Техническая часть
- Frontend: `src/components/HRDEmployeeMap.tsx` (мини-карта, кнопка в карточке, диалог с режимом аудитории), новая страница `src/pages/EmployeeMapPage.tsx`, маршрут в `src/App.tsx`, кнопка на `src/pages/HRDDashboard.tsx`.
- Backend: миграция `add_hr_task_audience` — колонка `audience_rules` (json) в `hr_tasks` (по образцу `courses.audience_rules`); контроллер `HrTaskAudienceController` с эндпоинтами справочника аудитории и предпросмотра количества, плюс материализация исполнителей при создании задачи и при синхронизации профиля.
- Демо-данные: `backend-laravel/app/Console/Commands/SeedDemoCompany.php` — новый шаг `assignCareerTracks()` (employee_career_assignments, career_goals, career_step_submissions).
- Тесты: PHPUnit на резолвер аудитории и на сидер треков; Vitest-смоук на диалог задачи.
