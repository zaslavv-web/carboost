# Исправление демо-контента, меню и редактора

## Что будет сделано

- Исправить и усилить догоняющий сидинг: гарантировать OKR и рабочий процесс для всех учетных записей выбранной компании, а также создание одной эталонной новости с заголовками, изображением, видео и файловым вложением.
- Добавить изменение порядка пунктов бокового меню с индивидуальным сохранением для пользователя, сохранив группы и вложенную иерархию.
- Исправить редактор публикаций: корректное применение типов абзаца/заголовка, сохранение выделения при работе с панелью и штатное выделение текста с клавиатуры.
- Добавить целевые проверки для сидинга и редактора, затем проверить сборку, тесты и живой интерфейс без ошибок.

## Технические детали

- Порядок меню хранится по пользователю и отдельно внутри каждой группы; родительские группы не смешиваются с дочерними пунктами.
- Сидинг останется идемпотентным и завершится ошибкой, если обязательные данные не были созданы.
- Проверка после изменений включает свежие build/runtime-сигналы и Playwright-сценарий редактора.
