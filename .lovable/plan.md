# Схема сценария оценки показывает только один блок

## Что не так

На `/scenarios` по кнопке «глаз» открывается схема, где виден только заголовок сценария и пустое поле.

Причина подтверждена по коду: `ScenarioSchemaViewer` строит граф только для одной конкретной формы данных — `questions`, `competencies`, `summary`, `key_points` (плюс отдельная ветка для массива-таблицы). А сценарии, которые лежат в базе (в том числе засеянные для демо-компании), имеют другую структуру: `brief`, `steps`, `criteria`. Ни один из известных просмотрщику ключей не находится, поэтому рисуется только корневой узел, а всё остальное молча пропускается.

## Что сделать

1. **Универсальный построитель схемы.** Вместо жёсткого списка ключей — обход структуры `scenario_data`:
   - строки/числа → узлы-факты («Описание», «Бриф», «Цель» и т.п.);
   - массивы строк → один узел-список (критерии, компетенции, теги);
   - массивы объектов → цепочка/сетка узлов (шаги, вопросы, задания) с сохранением порядка и связями от родителя;
   - вложенные объекты → отдельная ветка со своими дочерними узлами (глубина до 3 уровней, дальше — сворачивание с подписью «ещё N полей»).
2. **Понятные подписи полей.** Словарь для частых ключей (`brief`, `steps`, `criteria`, `questions`, `competencies`, `summary`, `key_points`, `description`, `max_score`, `title`) на русском/английском через i18n; неизвестные ключи выводятся как есть.
3. **Защита от «пустого экрана».** Если данных нет вообще или они не распознаны — вместо голого корня показывать понятное состояние: «Данные сценария пусты или в неизвестном формате» с подсказкой загрузить файл заново.
4. **Вкладка «JSON».** Переключатель «Схема / JSON» в шапке модального окна: сырой отформатированный `scenario_data` с копированием в буфер — чтобы HRD всегда видел, что реально хранится.
5. **Строка при JSON-строке.** Если `scenario_data` пришёл строкой (не декодированный JSON), пробовать `JSON.parse` перед построением графа — страховка от расхождений на бэкенде.
6. **Наполнение демо-сценариев.** В сидере демо-компании расширить `scenario_data` до полноценного кейса: описание, 3–5 шагов с задачами, вопросы с баллами, список компетенций — чтобы схема выглядела содержательно на боевом демо.
