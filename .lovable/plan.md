# Блок мотивации для всех ролей (не только сотрудник)

## Что сейчас есть (проверено в коде)

- Виджет валюты `CurrencyWidget` (баланс + последние операции) подключён только на устаревшей странице `src/pages/Dashboard.tsx`. Ни `EmployeeToday`, ни `ManagerDashboard`, ни `HrDashboard`/`HRDDashboard` его не показывают.
- В меню раздел «Мотивация» есть только у роли employee (Признания + Магазин). У manager, hr, hrd, company_admin этих пунктов нет вовсе; у hr/hrd есть только админские «Геймификация» и «Управление магазином».
- Страницы `/shop`, `/shop/:id`, `/cart`, `/my-orders`, `/recognition` в роутере доступны всем авторизованным — ограничение только в навигации.
- Передачи валюты между сотрудниками нет: в API нет ни одного маршрута для валюты, таблицы `currency_balances` / `currency_transactions` read-only через общий `/api/db`, признания (`peer_recognitions`) баллов не переводят.
- Отдельной витрины «как заработать валюту» нет: правила лежат в `gamification_reward_types` и видны только в админке.

## Что сделаем

### 1. Единый блок мотивации на всех дашбордах
Новый компонент `MotivationBlock` (на базе `CurrencyWidget`): баланс, последние операции, кнопки «Магазин», «Передать», «Как заработать». Добавим его на:
- `src/pages/employee/EmployeeToday.tsx`
- `src/pages/ManagerDashboard.tsx`
- `src/pages/HrDashboard.tsx`
- `src/pages/HRDDashboard.tsx` (и `hrd/Today.tsx` в правой колонке)

### 2. Пункты меню «Мотивация» для всех ролей
В `AppSidebar.tsx` добавить в секцию motivation для manager, hr, hrd, company_admin: «Признания», «Магазин», «Мои заказы». Админские пункты (Геймификация, Управление магазином) остаются у hr/hrd/админа дополнительно.

### 3. Способы заработать валюту
Новая страница `/motivation/earn`: список активных правил компании из `gamification_reward_types` (название, за что, сколько монет), плюс краткий блок «Как потратить». Ссылка из блока мотивации.

### 4. Передача валюты внутри компании
- Бэкенд: контроллер `CurrencyController` с маршрутами `GET /api/currency/balance`, `GET /api/currency/transactions`, `POST /api/currency/transfer`. Перевод — атомарная транзакция: проверка компании получателя, запрет перевода самому себе, запрет отрицательного баланса, лимит на перевод, запись двух строк в `currency_transactions` (kind `transfer_out` / `transfer_in`) и пересчёт `currency_balances`.
- Фронтенд: диалог «Передать монеты» (поиск коллеги, сумма, комментарий) в блоке мотивации; после успеха инвалидация баланса и истории.

## Технические детали

- Логика перевода — raw `DB::transaction` + `DB::table` (как в остальных быстрых контроллерах), без Eloquent-гидрации.
- Ограничения: только внутри своей `company_id`, сумма > 0, целое число, не больше текущего баланса; лимит по умолчанию настраивается в `company_currency_settings` (добавим поле `transfer_limit_per_day`, миграция с дефолтом).
- Клиент: расширим `src/hooks/useCurrency.ts` мутацией `useTransferCoins` и хуком `useEarnRules`.
- Компонент мотивации нейтрален к роли — берёт `useEffectiveUserId`, поэтому корректно работает в режиме имперсонации.
