# План: полная реализация HRD/Employee-сценариев

Принцип: задача не завершена, пока каждый пункт ниже не пройден в браузере под реальной HRD/Employee-сессией и не зафиксирован результат (страница открылась, данные видны, действие сохраняется, после reload состояние не теряется, в консоли и сети нет релевантных ошибок).

Верификация: единый финальный Playwright-прогон по всем разделам в конце. Промежуточные правки проверяются по логам сборки и runtime, без скриншота на каждый шаг.

## 0. Предварительная разведка

- [ ] Запустить Playwright под HRD на актуальном стенде.

- [ ] Для пустых разделов сверить реальные данные: есть ли строки по текущей компании и пользователю, какой company_id/user_id использует клиент, что возвращает backend.

## 1. Магазин и корзина

- [ ] Починить вход в карточку товара: маршрут `/shop/:id`, доступ, обработку отсутствующего товара, загрузку company_id, кликабельную область карточки.
- [ ] Починить добавление в корзину: единый user_id, company_id, upsert/insert/update, инвалидация query cache, читаемость корзины сразу после добавления.
- [ ] Добавить явное состояние ошибки на карточке и в корзине, чтобы 403/404/500 не выглядели как «пусто».
- [ ] Цепочка: `/shop` → клик по товару → `/shop/:id` → «В корзину» → запрос cart item → `/cart` → товар виден → перезагрузка `/cart` → товар остаётся.
- [ ] Кнопка «оплатить»: все товары из корзины перемещаются в раздел купленных товаров.
- [ ] HR-менеджеру поступает уведомление о новой покупке.
- [ ] При нехватке валюты добавление блокируется с понятной подсказкой; при оплате — предупреждение о недостаточном балансе и предложение сократить корзину.
- [ ] Workflow-товар: окно активации; автоматически формируется документ, обеспечивающий работу сервиса (выходной, изменение формата работы и т.п.).
- [ ] Материальный товар: окно с указанием реквизитов получения (место и время).
- [ ] Partner-товар (покупка чего-либо компанией): формируется задача у ответственного сотрудника о закупке товара/услуги у соответствующей организации.
- [ ] Проверить: товар открывается, добавляется, виден в корзине после перехода и после reload; при нехватке валюты добавление блокируется с подсказкой.
