# Починка автоопределения компании в `demo:seed-extras`

## Что происходит сейчас

Команда без `--company` ищет компанию только по e-mail из опции `--email` и по шаблону `%@demo.%`. На боевом сервере ни один пользователь под этот шаблон не подошёл, поэтому команда завершилась ошибкой «Компания не найдена».

## Быстрое решение прямо сейчас

Запустить с явным указанием компании:

```
php artisan demo:seed-extras --company='ООО "Демо"'
```

(или `--company=<uuid компании>`).

## Что изменить в коде

1. Расширить `resolveCompany()` в `SeedDemoExtras.php`:
   - явный `--company` (id или имя, как сейчас, но с точным сравнением по id и регистронезависимым по имени);
   - компания демо-аккаунта из `--email`;
   - компания по умолчанию `ООО "Демо"` по имени;
   - домены демо-почты: `%@demo.%` и `%@demo.pikrosta.ru`;
   - если ничего не нашлось и в базе ровно одна компания — берём её.
2. Если компания всё равно не определилась — вместо сухой ошибки печатать список доступных компаний (id, название, число сотрудников), чтобы сразу было что подставить в `--company`.
3. Добавить подтверждение выбора в вывод: «Компания определена автоматически: … (укажите --company, чтобы выбрать другую)».

## Проверка

- Прогон `php artisan demo:seed-extras` без аргументов на демо-базе: команда сама находит демо-компанию и доходит до блока самопроверки.
- Прогон с несуществующим `--company=xxx`: выводится список компаний и код возврата 1.
- Бэкенд-тесты остаются зелёными.
