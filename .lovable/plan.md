# SCORM 404: маршруты уже есть — проблема в файлах на диске

## Что подтверждено чтением кода

Маршруты и контроллер SCORM в проекте есть (проверено в `backend-laravel/routes/api.php` и `ScormController.php`):

- `POST /api/university/scorm/upload`, `/import`
- `POST /api/university/scorm/{courseId}/launch-ticket/{lessonId}`
- `GET /api/university/scorm/launch/{ticket}` (публичный, ставит cookie сессии)
- `GET /api/university/scorm/asset/{path}` (отдача статики)
- `GET /api/university/scorm/{courseId}/files` (диагностика содержимого пакета)
- `POST/GET /api/university/scorm/{enrollmentId}/cmi`

То есть совет «добавить маршруты и создать контроллер» к этому проекту не относится: 404 приходит не от роутера, а изнутри `asset()` — файл не найден на диске по запрошенному пути (`pages/01-intro.html`). Резолвинг уже терпимый (URL-декод, регистронезависимость, поиск по хвосту пути и по уникальному имени), поэтому наиболее вероятно, что файла в распакованном пакете действительно нет либо распаковка прошла частично.

## План

1. Снять фактическую картину: под HRD открыть `GET /api/university/scorm/{courseId}/files` и сравнить список файлов с тем, что запрашивает плеер, плюс посмотреть записи `scorm_asset_404` в логе.
2. По результату — одна из веток:
   - файла нет вовсе → чинить импорт: пересобрать распаковку ZIP (пропуск записей, вложенная корневая папка, кириллица в именах) и переимпортировать курс;
   - файл есть, но путь не совпадает → доработать `resolveHrefOnDisk`/`asset()` под конкретный вид пути из манифеста;
   - файл есть и путь верный → проверять права чтения у пользователя веб-сервера на `storage/app/private/scorm-packages`.
3. Добавить в `packageFiles()` контрольные поля: корень пакета, число файлов, `launch_url` каждого урока и признак «файл существует», чтобы расхождение манифеста и диска было видно сразу.
4. Прогнать сценарий на боевом: тикет → запуск → загрузка первого ассета, зафиксировать 200.

## Про предупреждение iframe

`allow-scripts` + `allow-same-origin` для SCORM обязательны (пакету нужен доступ к `window.parent.API`). Это ожидаемое предупреждение браузера, менять не нужно; изоляция обеспечивается тем, что содержимое отдаётся только владельцу сессии по подписанной cookie.

## Что нужно от вас

Ответ `GET /api/university/scorm/{courseId}/files` для проблемного курса (или сам ZIP-пакет) — по нему сразу видно, какая из трёх веток верна.
