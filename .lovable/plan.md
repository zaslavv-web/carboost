# Полный чек-лист правок (из документа пользователя)

## 1. Магазин + Корзина + Заказы
- [ ] Вход в карточку товара (клик по карточке → /shop/:id)
- [ ] Добавление в корзину работает (кнопка → товар в корзине)
- [ ] Корзина сохраняется между переходами
- [ ] Уведомления HR при заказе (workflow-товары создают задачу HR)
- [ ] Типы товаров: материальный / цифровой / workflow / partner
- [ ] Окна активации для каждого типа (OrderItemActivation)
- [ ] Баланс: блокировка покупки при нехватке
- [ ] Уведомление о нехватке баланса с «Убрать лишнее»

## 2. Чаты
- [ ] Профили из юзерпиков (аватар → профиль сотрудника)
- [ ] Создание 1:1 чата (поиск сотрудника → новый диалог)
- [ ] Связи отправителя корректны (имя/аватар отправителя)
- [ ] Список диалогов загружается

## 3. Таблица сотрудников
- [ ] Стаж работы отображается
- [ ] Быстрые фильтры работают
- [ ] Drill-down из аналитики (клик по KPI → отфильтрованный список)

## 4. Тесты и Pulse-опросы
- [ ] Импорт CSV для тестов
- [ ] Импорт CSV для опросов
- [ ] Статистика ответов (поимённый разрез)
- [ ] Audience rules (таргетинг по отделам/грейдам)

## 5. Адаптация + Приглашения
- [ ] Шаблоны адаптации наполнены контентом (шаги, чек-листы)
- [ ] Приглашения: отправка работает (email, ФИО, должность, отдел)
- [ ] Приглашения: список отображается после отправки
- [ ] Права доступа корректны

## 6. Performance Reviews + Документы
- [ ] Циклы оценки созданы и наполнены
- [ ] Performance 360: приглашения работают
- [ ] HR-документы: загрузка работает
- [ ] HR-документы: доступ к документам подчинённых

## 7. Финальная приёмка
- [ ] Единый Playwright-прогон под HRD
- [ ] Единый Playwright-прогон под Employee
- [ ] Все разделы без ошибок в консоли
